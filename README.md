# TradingDemoADSS

## Run the Expo app

Install the dependencies:

```bash
npm install
```

Start the Expo development server:

```bash
npx expo start
```

From the Expo CLI, press `i` to open the iOS simulator or `a` to open the Android emulator. You can also scan the QR code with the Expo Go app on a physical device.

### iOS simulator

Requires macOS with Xcode and an iOS simulator installed.

```bash
npm run ios
```

### Android emulator

Requires Android Studio with an Android emulator configured.

```bash
npm run android
```

For a physical device, install Expo Go and make sure the device and development computer are on the same network, then scan the QR code shown by `npx expo start`.
